This connects Xero's accounting API to Excel with VBA macros, so finance teams can pull live data into spreadsheets they already use. The hard part was OAuth2 in VBA, doing token exchange and refresh in a language with no support for it.

I wrote up the whole auth flow on Medium. The end result was no more manual exports and copy-paste reconciliation.
