This project connects Xero's accounting API directly to Excel through VBA macros, letting finance teams pull live financial data into the workbooks they already use. The hardest part was implementing OAuth2 authentication natively in VBA — token exchange, refresh flows, and secure credential handling in an environment that was never designed for it.

I documented the approach in a Medium article, "Navigating OAuth2 Authentication in VBA," which walks through the authentication flow step by step. The result is an automated financial data workflow that replaces manual exports and copy-paste reconciliation.

The project reflects my accounting background: instead of forcing accountants onto new tools, it brings the automation to where their workflows already live.
